Small status / category label. Tone carries meaning: `gold` = pépite, `success` = good DPE / fresh, `danger` = overpriced / blocked, `info` = source/portal.

```jsx
<Badge tone="gold" dot>Pépite</Badge>
<Badge tone="success">DPE C</Badge>
<Badge tone="info">SeLoger</Badge>
<Badge tone="danger" solid>-18% marché</Badge>
```
